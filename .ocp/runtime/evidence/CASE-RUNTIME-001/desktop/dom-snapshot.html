미구현

출력 언어

에이전트와 보고서의 출력 언어는 아직 거버넌스된 워크스페이스 설정이 아닙니다.

현재 구현 경계인터페이스 언어는 핵심 화면에 우선 적용됐고 일부 상세 패널은 부분 한글화 상태입니다. 표시 번역과 거버넌스된 출력 언어는 아직 명세 단계입니다.
